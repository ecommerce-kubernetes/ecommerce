# 장바구니 유스케이스

## 장바구니 상품 추가

### 목적

사용자가 선택한 상품을 장바구니에 추가한다.

### 조건

- 사용자는 로그인 되어있어야 한다.
- 추가하려는 상품은 판매중이어야 한다.

### 기본 흐름

1. 사용자가 요청한 상품의 정보를 조회한다.
2. 상품이 장바구니에 추가할 수 있는 상품인지 검증한다.
3. 장바구니에 해당 상품과 수량을 추가한다.
4. 변경된 장바구니를 저장한다.

#### 대안 흐름

- **1a. 장바구니가 존재하지 않는경우**
    1. 기본 흐름 2까지 진행한다
    2. 사용자 식별자로 장바구니를 생성한뒤 기본흐름 3을 진행한다
- **2a. 상품 조건이 만족하지 않는 경우**
    1. 예외를 발생시키고 흐름을 종료한다.

## 장바구니 조회

사용자의 장바구니의 항목 정보를 반환한다.

### 조건

- 사용자는 로그인 되어있어야 한다.

### 기본 흐름

1. 사용자의 장바구니를 조회한다.
2. 조회한 상품 식별자로 상품 정보를 조회한다.
3. 조회한 상품 정보와 함께 장바구니 항목의 최신 정보를 반환한다.

### 대안 흐름

- **1a. 장바구니가 없는 경우**
    1. 빈 리스트를 반환한다.
- **2a. 장바구니에 상품이 없는 경우**
    1. 빈 리스트를 반환한다.
- **3a. 장바구니의 상품이 상품 조회에서 누락된 경우**
    1. 누락된 상품은 기본정보만 포함하여 판매 불가 상태로 반환한다.
- **4a. 장바구니에 담긴 상품이 판매 불가능한 경우**
    1. 판매 불가능한 상품은 판매 불가 상태로 반환한다.

## 장바구니 항목 수량 변경

사용자의 장바구니 항목의 수량을 변경한다.

### 조건

- 사용자는 로그인 되어있어야 한다.

### 기본흐름

1. 사용자의 장바구니 항목을 조회한다.
2. 조회한 항목의 수량을 변경한다
3. 변경된 장바구니 항목을 반환한다

### 대안 흐름

- **1a. 장바구니에서 해당 상품이 없는경우**
    1. 예외를 발생시키고 흐름을 종료한다.
