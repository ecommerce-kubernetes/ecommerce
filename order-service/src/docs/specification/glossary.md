# OrderService 용어 사전

## 장바구니

### 도메인 용어

| 용어      | 영문       | 설명                          | 관련 도메인 |
|---------|----------|-----------------------------|--------|
| 장바구니    | Cart     | 사용자가 주문을 위해 상품을 임시로 담아두는 공간 | Cart   |
| 장바구니 항목 | CartItem | 장바구니에 담긴 개별 상품              | Cart   |

### 식별자

| 이름         | 설명          |
|------------|-------------|
| cartId     | 장바구니 식별자    |
| cartItemId | 장바구니 항목 식별자 |

### 장바구니 항목 상태

| 상태           | 의미    |
|--------------|-------|
| AVAILABLE    | 주문 가능 |
| NOT_FOR_SALE | 판매 불가 |
| OUT_OF_STOCK | 재고 부족 |

## 주문서

### 도메인 용어

| 용어     | 영문             | 설명                                                   | 관련 도메인     |
|--------|----------------|------------------------------------------------------|------------|
| 주문서    | OrderSheet     | 주문 생성 전 주문 할인 정보, 배송정보, 가격 관련 정보를 계산해 임시로 생성된 주문 데이터 | OrderSheet |
| 주문서 상품 | OrderSheetItem | 주문서에 포함된 주문 상품 정보                                    | OrderSheet |
