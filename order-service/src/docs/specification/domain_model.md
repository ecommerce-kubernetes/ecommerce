# 도메인 모델

## OrderService
- **목적:** 사용자의 장바구니 상품 담기와 주문서 작성, 최종 주문 생성 및 결제 연동까지 전체 구매 흐름을 관리한다.
- **특징:** 분산 트랜잭션 처리를 위해 오케스트레이션 기반의 SAGA 패턴을 적용하여 주문 서비스가 재고, 쿠폰, 포인트 트랜잭션 흐름을 제어한다.

### 주요 도메인
- **장바구니(Cart) :** 사용자의 구매 대기중인 상품 목록을 관리
- **주문서(OrderSheet) :** 최종 주문 생성 전, 쿠폰 적용 및 결제 예상 금액이 계산된 임시 주문 
- **주문(Order)  :** 사용자의 최종 구매 확정 내역 및 상태 관리
- **결제(Payment) :** 해당 주문의 결제 정보, PG 사의 결제 정보 및 상태 관리

## 엔티티
### 장바구니(Cart)
사용자 1명당 1개의 생명주기를 갖는 장바구니 애그리거트 루트.

#### 속성
| 필드명       | 타입   | 설명                    |
|-----------|------|-----------------------|
| id        | Long | 장바구니 식별자              |
| userId    | Long | 장바구니의 소유자 식별자         |
| cartItems | List | 장바구니에 담긴 개별 상품 항목 리스트 |

#### 행위 
- 항목 추가: 장바구니에 상품을 추가한다.
- 항목 삭제: 장바구니에 담긴 항목을 삭제한다.
- 항목 수량 변경: 장바구니에 담긴 항목의 수량을 변경한다. 

#### 규칙 
- 장바구니에 추가하려는 항목이 이미 장바구니에 존재하는 경우 기존 항목의 수량을 증가시킨다.
- 장바구니의 최대 항목 개수를 초과하는 경우 더이상 장바구니에 항목을 추가할 수 없다.
- 장바구니에 존재하지 않는 항목은 수량을 변경할 수 없다.
- 장바구니에 존재하지 않는 항목은 삭제할 수 없다.

### 장바구니 항목(CartItem)
장바구니에 담긴 개별 상품 정보를 관리하는 하위 엔티티

#### 속성

| 필드명              | 타입      | 설명          |
|------------------|---------|-------------|
| id               | Long    | 장바구니 항목 아이디 |
| cart             | Object  | 장바구니        |
| productVariantId | Long    | 상품 변형 아이디   |
| quantity         | Integer | 담은 수량       |

#### 행위
- 수량 변경: 항목의 수량을 변경한다.

#### 규칙
- 장바구니에 담긴 항목의 수량은 최소 1개 이상이여야 한다.
