# OrderService 에러 명세

## 공통 에러

| 상태 코드 | 에러 코드        | 메시지             |
|-------|--------------|-----------------|
| 400   | VALIDATION   | 입력값이 올바르지 않습니다. |
| 401   | UNAUTHORIZED | 인증이 필요한 접근입니다.  |
| 403   | FORBIDDEN    | 요청 권한이 부족합니다.   |

## 장바구니 (Cart)

| 상태 코드 | 에러 코드                      | 메시지                    |
|-------|----------------------------|------------------------|
| 404   | CART_NOT_FOUND             | 장바구니를 찾을 수 없습니다.       |
| 404   | CART_ITEM_NOT_FOUND        | 장바구니에서 항목을 찾을 수 없습니다.  |
| 404   | PRODUCT_NOT_FOUND          | 존재하지 않는 상품입니다.         |
| 409   | CART_SIZE_LIMIT_EXCEEDED   | 장바구니 최대 항목 개수를 초과했습니다. |
| 409   | INVALID_CART_ITEM_QUANTITY | 항목 수량이 유효하지 않습니다.      |
| 409   | PRODUCT_NOT_ON_SALE        | 판매중인 상품이 아닙니다.         |
